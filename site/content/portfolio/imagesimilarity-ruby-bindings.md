Ruby binding to image comparison algorithms (in C++ & Ruby)

Ruby bindings to the following image comparison algorithms. See [this](/detecting-similar-and-identical-images-using-perseptual-hashes/) article for more information. Github [link](https://github.com/Kandepet/ImageSimilarity).

1. Average Hash
2. pHash
3. Color Histogram
4. Multiresolution Haar wavelet decomposition
